# 7.0.106 USB 拔插充电历史诊断

## 目的与边界

7.0.105 已确认温度来自 BQ27220 内部，充电禁止上限为 45°C，BATG_EN=0、PFC=0。仓库原理图中充电器 CE 接 VBUS，未接电量计控制输出。CHGINH=1 不等于实际充电器被禁止；当前有效瞬时电流为 0 mA，仍需记录 USB 拔插时的电流变化，才能区分显示判定与实际充电/测量问题。

本版本保持充电判定、容量参数、温度阈值及 UI 行为不变，先取得完整变化过程。不会清除 CHGINH、虚构充电状态或把 SOC 改成 100%。

## 实现

- 电池任务单独拥有一个固定 64 条的 RAM 环形缓冲，不放在任务栈上，不动态分配。
- 保存每次采样尝试；正常约 8 秒一次，保留最近约 8 分钟。错误重试期间间隔随原退避变化。
- 每 64 秒到期后，在下一次采样完成时输出全部历史；正常约 64～72 秒，繁忙或采样错误时可能更长。
- 无独立 USB 插拔检测，不声称插回立即触发；电脑重新连接串口后，等待下一次周期输出即可。
- 不额外访问 I2C，不写 NVS/Flash/SD，不上传云端；不持有电池服务锁或 I2C 锁打印，每 8 条让出一个调度 tick。
- 环形缓冲覆盖最早记录。设备重启或电池服务重新启动时清空，序号从 0 开始。

## 一次测试步骤

1. 升级到 7.0.106，连接 USB，确认 `charge history enabled revision=charge-history-v1`，等待设备稳定至少 1 分钟，保存日志。
2. 拔掉 USB，保持设备用电池运行约 2 分钟。观察屏幕、唤醒等功能是否继续工作，并记下拔出时间。无需在拔出期间获取电脑串口日志。
3. 插回 USB，重新连接串口并保持记录至少 90 秒，直到收到一组完整的 `charge history begin`、`row`、`end`。若读取失败导致退避，继续等待完整一组。
4. 提供插回后的完整日志，并说明拔插时间、拔出期间是否继续工作以及板载充电指示灯情况。

重新打开串口时避免软件触发 DTR/RTS 复位，不执行烧录或主动重启。如果出现新的开机日志，之前的 RAM 历史已丢失，不能把空历史解释为没有电池电流。

## 历史格式

`charge history row=` 后按以下顺序输出 CSV，首尾日志用于检查一组是否完整：

```text
seq,t_ms,mV,mA,soc,display,temp_C,remaining_mAh,fcc_mAh,flags_hex,quality_hex,state_hex,err_hex
```

`t_ms` 是原采样尝试时的启动后时间；日志行前缀时间是回放时刻。应按 CSV 中的 t_ms 判断拔插变化，不能把一批历史当成同一时刻的新采样。不同周期重复回放同一记录，按同一次启动内的 seq 去重。

- quality 位 0：本次完整遥测有效；位 1：本次电压/状态组有效；位 2：发布快照有效；位 3：发布快照过期。正常为 `07`。
- 本次遥测无效时，容量/电流等可能是保留值，不能作为新测量。状态组无效时 flags 输出 `0000`，必须结合 quality 位 1，不能解释为硬件标志已清零。
- state 位 0：发布的 charging；位 1：发布的 full。
- flags 与 err 是十六进制；电流有符号，正值为充电方向，负值为放电方向。err=0 代表本次读取成功。

## 如何据此解决问题

| 有效历史数据表现 | 下一步判断/处理 |
| --- | --- |
| 拔出明显负电流，插回明显正电流超过 20 mA，但 charging=0 且 CHGINH=1 | 实测电流有充电方向证据，重点修正图标判定与本板温度来源/充电控制语义不匹配的问题；不修改充电保护阈值 |
| 拔出负电流，插回长时间接近 0 | 电流采样能响应供电变化，但无明显净充电；核对 U1 CHRG/DONE、VBUS、BAT、电池端实际电压及供电能力 |
| 插回后仍明显负电流 | 检查 USB 供电、线缆、充电路径和系统负载；显示图标不能解决净放电 |
| 拔出仍运行，但长时间电流始终为 0 | 检查电流测量校准、采样电阻及接线、实际硬件版本；不能以此认定电池没有放电 |
| 拔出即关闭或重新插入发生重启 | 优先检查电池连接、保护板与电源保持；RAM 历史无法跨重启保留 |
| quality 或 err 异常 | 先解决采样有效性问题，不把保留值当成真实充电趋势 |

## 软件验证

`tools/test-battery-history.py` 覆盖环形覆盖与时间顺序、64 位时间、周期边界、串口不可用后恢复输出、负电流、失败/部分有效采样和服务重启清空。既有电源边界回归与正式产物校验一并执行。主机模拟不能替代真机 USB 拔插、电流和温度测量。
