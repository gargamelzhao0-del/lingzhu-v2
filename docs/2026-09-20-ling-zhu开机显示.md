## 启动顺序

1. 屏幕复位及初始化期间保持背光关闭。
2. 清屏后，逐行将完整 Logo 写入屏幕。
3. 写入成功、显示驱动初始化完成后点亮背光。
4. LVGL 和正式 UI 初始化期间，刷新输出门保持关闭，屏幕保留 Logo。
5. 主界面或配网页面对象及状态监听器准备好后打开输出门，强制整屏重绘，替换 Logo。

不增加固定等待时间；显示时长随实际启动耗时决定。显示初始化或像素发送出错时不会提前点亮部分图片；背光早期启用失败会在 UI 初始化后重试。没有在 LVGL 运行期间引入第二个绘图任务。
