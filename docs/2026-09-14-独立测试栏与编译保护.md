## 页面与功能

测试配置下，控制中心顺序为：状态 → 菜单 → 测试。在菜单页继续左滑进入测试页，右滑回菜单。
原状态/菜单动画保留；测试页切换在手势释放确认后直接完成，不复用只支持两页的截图合成器。
关闭总开关后恢复原两页结构，不创建测试页面、第三个指示点或测试字体对象。

| 测试项 | 当前行为 |
|---|---|
| 云端断网 | 已接入原模拟断网控制，开关 ON 表示模拟云端离线。保留物理 Wi-Fi 和局域网，以便独立 SD 测试网关可达 |
| MIC3 参考链路 | 预留禁用开关，显示“待接入 / LOCKED”，无点击动作，不产生测试音或切换麦克风 |
| 实时模式 | 预留禁用开关，显示“待接入 / LOCKED”，不启用 AEC、不改变云端协议或打断策略 |

断网开关已从菜单音量卡片移出。音量卡恢复原尺寸。

等待执行时显示 WAIT，成功后显示实际 ON/OFF；拒绝或超时后回到状态快照。
配网、OTA 占用通信时的原拒绝保护保留。测试状态不写 NVS，重启默认不模拟断网。

## 编译保护

`main/test_controls.h` 是测试 UI 与执行代码共同使用的保护入口。

| 配置 | 默认值 | 作用 |
|---|---|---|
| `CONFIG_NUWAX_TEST_PANEL_ENABLE` | n | 测试页与该页测试效果的总开关 |
| `CONFIG_NUWAX_TEST_NETWORK_ENABLE` | 总开关启用后默认 y | 单独控制模拟云端断网入口和执行能力 |

`NUWAX_TEST_NETWORK_ENABLED` 必须同时满足总开关和断网子开关。
关闭总开关即使误设断网子开关，也不会生效。
主任务拒绝禁用功能的 action；Wi-Fi 底层 setter 也返回 ESP_ERR_NOT_SUPPORTED，getter 返回 false。
因此保护不依赖按钮隐藏，也不能通过绕开 UI 调用启用模拟断网。

测试配置已在 `sdkconfig.sd-replay-test.defaults` 显式打开两个开关。
正式配置保持总开关 n。已有 sdkconfig 中的显式值优先于 defaults，切换正式构建时应在
menuconfig 的 Developer test panel 中关闭总开关，不能只修改 defaults 后认为已有配置自动关闭。

SD 测试网关仍由 `CONFIG_NUWAX_OFFLINE_AUDIO_REPLAY_TEST_ENABLE` 独立选择。
测试页面开关不代表切换补传服务器；关闭测试页也不会自动修改既有网关配置。

## 后续扩展规则

- 页面、字体位于 `main/nuwax_ui_v28/test/`，都受总开关保护。
- 新测试效果增加单独 Kconfig 子项，依赖总开关；危险或未验证的效果默认 n。
- 增加真实执行接口后再启用对应按钮；不要仅翻转 UI 本地变量假装功能已开启。
- MIC3 验证应由音频任务执行，并仲裁会议、监控、播放等麦克风占用。UI 不直接运行诊断或阻塞等待。
- 实时模式需要设备采集、AEC 和云端能力条件同时满足后确认；关闭测试开关时应保证没有测试分支改变生产流程。
- 测试请求和实际状态分开，上报执行结果，处理拒绝、超时、退出页面和重启。
