# 翻页终点交接与分页快照优化

承接固件 `b96f0a916…` 和 c64872bd 日志。此前下拉串页已修复，操作期间仍有约 130 ms 绘制长帧。本轮未调整 Wi-Fi、SD 上传协议、任务优先级或显示 DMA 参数。

## 代码变更

1. **补齐手势终点提交路径。** `nuwax_drawer_page_finish_drag()` 在手指已拖到目标进度时，原先直接恢复实时页面；现在沿用 `page_transition_completed()`，先提交缓存最终帧，再交回实时控件，避免这一分支提前退出缓存并触发额外整页绘制。若没有缓存则仍直接完成。
2. **检查目标页的脏标记。** `presented_frame_cb()` 原先在更新 `s_page` 前读取出发页的脏标记，可能漏掉动画期间变化的目标页。现在读取待完成的目标页，提交缓存后刷新最新数据。
3. **减少分页快照准备工作。** 在 LVGL 已完成布局的 `RENDER_START` 中，已知分页裁剪对象使用现有缓冲和标准绘制任务生成图像，省去再次布局检查和递归遮挡查找。保留透明度、文字、裁剪和软件绘制行为；尺寸或外绘范围不符合约束时回退通用快照函数。没有增加帧缓冲。
4. **补充可归因统计。** 每两秒按需记录 `motion work`：分页快照构建/复用次数、准备路径/回退次数、快照平均和最长耗时、最终帧交接平均和最长耗时。耗时为经过时间，可能包含调度等待。手动翻页从拖动开始也记录性能，避免拖到终点后完全没有 page 性能记录；手指停留会计入该持续时间。

本轮没有消除所有分页图像生成工作，不能仅根据代码推导实机达到 40 FPS。新增统计用于确认剩余长帧来自快照、交接还是其他绘制路径。
