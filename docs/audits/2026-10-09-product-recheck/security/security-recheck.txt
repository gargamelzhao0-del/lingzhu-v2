五、OTA 签名、硬件 Secure Boot 和连续升级：明确边界

近期远程加固可以采用 ESP-IDF 已支持的“无硬件 Secure Boot 的 signed-app OTA 验证”，但它不是打开普通 app 的 Secure Boot 开关那么简单。C:/esp/v6.0/esp-idf/docs/en/security/secure-boot-v2.rst:895–905 及 secure_boot_signatures_app.c:160/232：更新验签信任当前运行 app 的首个签名块公钥；最初 app 必须已正确签名。此模式不能抵御有 flash 写能力的攻击者，也不能把旧无签名运行镜像当作已经建立的可信根。官方说明：https://docs.espressif.com/projects/esp-idf/en/release-v6.0/esp32s3/security/secure-boot-v2.html#signed-app-verification-without-hardware-secure-boot

过渡方案要有第一份签名桥接固件的可信交付、完整包（含padding/signature）大小与哈希、目前 controller 的 pending-image full hash一致性、随后第二次正确签名升级、错签/无签升级拒绝、rollback 到旧无签镜像会重新开放边界的处置。不得未经实机两次升级试验宣称一键启用完成。软件验签可以保护远程更新发布授权；全硬件安全另走新制造批次：签名 bootloader/app、预定公钥摘要/eFuse策略、Flash Encryption密钥保护、下载调试口策略及恢复工艺，经稳定供电工位执行与读回验收。当前普通 app OTA 路径不写 bootloader/partition table/eFuse，不能用该路径直接承诺开启硬件 Secure Boot 或安全烧 fuse。本轮没有烧写任何 eFuse。

签名私钥留在受控签名系统；设备只拿验证公钥/摘要。新版本同时验证生成的完整 signed BIN 小于当前4 MiB manifest上限和0x420000 OTA槽。正式 unsigned BIN 当前约3.85 MB，余量不是后续增功能/加签后仍可直接通过的保证。端点白名单可减小暴露面，不能替代发布签名；签名验证也不能替代 WSS 对 deviceSecret/音频的保护。

六、与存储审查对齐的绑定代际/隐私边界

cloud_config v1 只有 version、device_id、cloud_url、device_secret。以上新 secret 提交链确实改变了随后连接身份，却没有同步给旧 SD archive 写入可证明的 owner。存储专项证据：offline_audio_spool.c:191–205 header 无 owner，:3659–3666 begin 只有片段信息，:3684–3691 必须通过服务器 begin ACK 才可进入 :3718 的payload发送；:4278–4321 用当前epoch/hello启动。结论是“新绑定连接会提出旧档回传，服务器接受后会发送；B最终可见性取决云端”，不写成已抓到 B 看见数据。

设备本地随机 binding_generation 只能覆盖设备实际看见的换主事件；deviceId固定、deviceSecret可能不变；secret hash 会把普通轮换误当换主。云不通知的 silent换主，纯设备无法推断。云应通过可信 WSS/authenticated hello 提供稳定 owner_scope_id+ownership_epoch：同一主人换网/旋转凭据保持scope，换主递增epoch；begin/ACK也绑定此scope。设备把该scope与归档、回传任务和解绑事务绑定，切换时停旧writer/replay并持久化边界。没有scope的旧档绝不默认归当前新主人：原owner证据+受控迁移才能准入，否则隔离。若近期不能改协议，只能做“已观察到显式解绑/重新claim/身份配置变化时保守隔离旧档”；会牺牲一部分合法积压同步体验，且不能宣称覆盖silent换绑。

用户恢复出厂应是明确契约：清用户 Wi-Fi/云凭据/绑定scope及用户归档（或密钥销毁并满足真实安全擦除目标），保留制造身份；离线状态先完成本机隔离，云解绑回执后再完成账号层状态。普通换Wi-Fi不能等同恢复出厂。本轮未取得已发布 APP/云/设备全链路 reset+解绑验收，因此只作为必须验证的交付项，不根据函数名称缺失另造P1。

七、分阶段交付、体验变化与验收

阶段A：发布前清点/锁住风险
固件负责人将实际正式宏、云域名映射、生产凭据来源纳入 mandatory release gate（现有可选脚本不等于默认强制）。APP/云负责人交付已发布APP QR/secret下发行为、WSS真实端点及owner claim语义。对未验证绑定归属的旧档先阻断自动回传，保留可恢复数据。出货前逐台凭据与制造校验必须完成；旧板不假装已满足新表/eFuse流程。

阶段B：兼容桥接
先上可信 WSS/owner握手能力，再发布可读旧配置且有journal的迁移固件；完成端点、账号、owner一致性预检后切换并轮换secret。保持旧固件回滚恢复途径但明确其安全限制，不默默回退ws。APP可用原QR协议携带逐台PoP，实测旧/新APP兼容后设最低支持版本。旧档无法证明归属时APP解释“旧录音待原账号确认/本地隔离”，而不是悄悄上传或直接清空。

阶段C：新生产安全根
工装烧录经验证的新分区表、factory_nvs、签名镜像与硬件安全配置；逐台验证UID/label/verifier一致、factory不被用户reset擦除、固件验签与恢复行为。旧设备普通app OTA仅获得可行的软件保护；需硬件安全根/独立工厂分区的旧板列为另行受控升级工艺。

用户体验对照：
首次配网：此前DEV共享口令由二维码/APP流程使用；修复后每台独立标签/恢复码，仍扫码一次，但首次建立官方账号绑定要等可信云确认；缺标签有明确售后恢复，不能共享万能码。
普通换网：此前Wi-Fi成功即提交新云字段，云失败可能后续再配；修复后同owner保留录音与账户，云预检失败可重试/保留旧事务，不误提示绑定完成。
WSS迁移：此前ws使用者无额外操作；修复后多数可自动迁移，首次TLS握手可能增加延迟，实际数值板测；无法认证的新端点显示明确原因，不删除原绑定。不能承诺用户完全无感。
换主/解绑：此前本机旧档可能由新连接提出回传；修复后旧档隔离，新主人只可访问新scope；原主恢复/删除有明示流程。
OTA：此前有完整性/健康回滚但命令信任随控制链路；修复后wrong-key/unsigned包在写入验证阶段拒绝，正常版本仍保留回滚；首个桥接与连续升级需额外灰度验收。
用户恢复出厂/NVS异常：修复后用户reset清个人状态且保留出厂凭据；factory异常进入明确恢复模式，用户可能需要售后，避免静默擦掉后永久无法配网。

必须执行的验收用例（未做的不要标为PASS）：
1. 新旧APP分别扫描两台逐台标签；A凭据不能配B；错username/PoP、过期窗口、旧BLE session、切换连接重放均拒绝；正确session正常配网。证明标签p来源及不使用硬编码DEV值。
2. 正确Wi-Fi但云secret错误、未列名WSS、证书过期/错host/不可信根/重定向：不得提交已成功绑定、不得向未认证端点发敏感数据；原有效绑定/事务可恢复。官方cloud claim拒绝要设备可见。
3. 存有旧ws配置分别升级桥接/strict；旧wss配置也走同矩阵；在stage/预检/commit/secret轮换每个边界断电，恢复后最多一个有效事务且绑定不被错误擦除；已成功WSS后禁止静默回ws。主机12PASS只是目前陷阱证据，不是迁移修复PASS。
4. 抓包验证成功WSS不暴露token/hello secret；能篡改旧ws网络的代理不能通过新TLS；可信endpoint预检含owner一致性，不以任意101/pong代替claim。APP/云最低版本与离线旧机升级路径明确。
5. WSS冷连/重连/长证书链与OTA HTTPS并行，叠加真实音频/回传压力；记录内外堆及largest block低点、TLS失败率、握手延迟、120秒健康窗口内成功率；不得因低内存静默降级明文。
6. 正确签名连续两次升级+跨多个版本升级；错签/无签/破坏包/错size/SHA/project/version均拒绝；signature含padding包的manifest hash与新机pending hash一致；回滚到旧unsigned版本的边界有可执行处置。
7. OTA在下载中、esp_ota_end前后、set_boot后、mark-valid前后、accepted写入前后、pending清除前后掉电；应启动已验证旧版或恢复一致的新版本，不接受未确认身份或错误版本floor；关键硬件health失败/服务离线要按既定窗口回滚。
8. 制造模拟NVS NO_FREE_PAGES/NEW_VERSION_FOUND与普通NOT_ENOUGH_SPACE分别验证；用户分区恢复不触及独立factory；factory缺失/损坏/标签不匹配不得回退DEV。旧分区表设备不得因app升级误认为已有factory_nvs。
9. A录音→离线→显式解绑→B绑定；不允许A旧档payload进入Bscope；server拒begin时本机不发chunk。再测只换Wi-Fi、同owner secret轮换、云端silent换主、旧无scope档；前二者保留合法体验，后两者受真实协议约束/隔离。
10. 在线/离线恢复出厂、取消配网、断电重启：个人状态/旧录音清理或隔离遵循产品承诺，制造身份与后续正常配网保留；相关日志不打印PoP/secret。
