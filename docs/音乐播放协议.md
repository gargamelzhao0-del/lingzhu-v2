# 音乐播放协议

云端下发播放命令
```json
{
  "type": "device_command",
  "command": "play_music",
  "request_id": "music_req_20260821_000001",
  "url": "https://cdn.example.com/audio/song_001.mp3",
  "format": "mp3"
}
```

说明：`url` 必须为 HTTPS，`format` 当前固定为 `mp3`。设备端解码后按
原文件采样率输出；44.1/48 kHz 音乐不再统一降为 16 kHz。当前设备只有一个扬声器，
立体声按左右声道平均输出。未启用音乐功能的固件拒绝该命令。

播放命令 ACK
```json
{
  "type": "device_command_ack",
  "request_id": "music_req_20260821_000001",
  "command": "play_music",
  "ok": true,
  "message": "accepted"
}
```

拒绝示例:
```json
{
  "type": "device_command_ack",
  "request_id": "music_req_20260821_000001",
  "command": "play_music",
  "ok": false,
  "message": "music playback disabled"
}
```

开始播放：
```json
{
  "type": "music_playback_status",
  "request_id": "music_req_20260821_000001",
  "state": "playing"
}
```
播放完成：
```json
{
  "type": "music_playback_status",
  "request_id": "music_req_20260821_000001",
  "state": "completed"
}
```
播放失败：
```json
{
  "type": "music_playback_status",
  "request_id": "music_req_20260821_000001",
  "state": "failed"
}
```

设备播放中断：
```json
{
  "type": "music_playback_status",
  "request_id": "music_req_20260821_000001",
  "state": "cancelled"
}
```

停止协议：
云端下发
```json
{
  "type": "device_command",
  "command": "stop_music",
  "request_id": "stop_req_20260821_000001"
}
```
设备ack
```json
{
  "type": "device_command_ack",
  "request_id": "stop_req_20260821_000001",
  "command": "stop_music",
  "ok": true
}
```

## 7.0.180 播放及打断规则

以上云端命令、ACK 和状态字段保持不变。`accepted` 表示请求已接收，
`playing` 在实际送出音频后上报；下载或解码失败上报 `failed`。
终态可附带可选 `reason`，用于区分 `replaced`、`head_touch`、`shake`、
`cloud_stop`、`higher_priority`、`connection_changed` 或具体错误。

| 场景 | 设备处理 |
| --- | --- |
| 收到新的音乐请求 | 停止当前对话采集、唤醒和 TTS，等待音频资源释放后缓冲音乐 |
| 音乐播放期间 | 不聆听、不响应唤醒词，不播放普通云端 TTS 或语音通知 |
| 摸头、摇晃 | 停止音乐；不额外触发云端对话请求 |
| 再次收到播放请求 | 中断旧歌，保留最新一首；旧请求上报 cancelled |
| 会议、监控开启 | 停止音乐，恢复语音采样率后交给会议/监控采集 |
| OTA、关机、低电量关机、配网 | 停止音乐并让出音频资源；低电量提示及关机规则沿用现有流程 |
| 云端 stop_music | 停止当前音乐及尚未开始的音乐，不要求携带原播放 request_id |
| 正常播完或用户停止 | 回到休眠待唤醒；不自动续播，不自行进入聆听 |
| 云端连接断开或连接代次变化 | 云端下发的音乐停止，避免旧连接的命令继续执行 |
| 会议、监控、OTA等高优先级状态正在进行 | 拒绝新的音乐请求，不反向打断这些功能 |

`stop_music.request_id` 是停止命令自身的编号，音乐取消状态使用原播放请求编号。
对话用的 `stop_playback` 仍按 turn_id/playback_id 匹配旧语音，不能用来停止无关音乐；
停止音乐请使用上面的 `stop_music`，无需新增协议。

表情：缓冲时为平静表情，开始输出后为开心表情。结束后恢复休眠；会议、监控、
OTA、低电量页面接管时让出显示，不继续覆盖这些页面。摸头保留本地触摸反馈。

播放器采用有界缓冲，不整首装入内存，不写 SD 卡。支持直接返回音频的 HTTPS 200
响应（Content-Length 或 chunked），暂不跟随重定向。默认文件上限 32,000,000 字节。
下载超时、文件截断、解码失败会终止本次播放并释放资源，不自动重播。

本地测试网关使用独立开发开关和 HTTP 地址，发送/中止按钮复用相同播放与打断流程。
详见 [音乐测试网关说明](../tools/music-url-test/README.md)。

## 7.0.181 异常恢复修订

本次不增加或修改通信字段。设备端补充以下处理：

- I²C 读写或总线锁失败时，采样率配置判为失败；音乐结束后只有语音时钟恢复成功，才允许麦克风重新接管。持续故障期间保持静音并重试。
- HTTP 响应头读取失败直接结束本次下载，不把错误码当作未知文件长度。
- 网关中止指令统一在设备主流程去重后执行，延迟到达的重复中止不会影响下一首歌。
- 云端重连后，同一请求号按新的连接代次重新受理，避免误认为旧请求已经执行。
- 音乐接管时若收到已排队的摸头事件，结束音乐并释放触摸占用；不触发云端对话。
- 分配内存或创建播放任务失败时，状态明确转为失败，不停留在缓冲中。
- 音频资源和语音时钟恢复后即可回到待唤醒，不等待较慢的 HTTP 清理；下一首音乐仍等待旧下载任务退出，避免两首共用状态。

主机回归和故障注入只验证软件处理。实板采样率切换、听感、打断耗时及长时间运行仍需烧录测试。

## 7.0.182 音频通道交接修复

7.0.181 在语音输出已预初始化时可能下载成功却无法播放：普通空闲处理只静音，仍保留 TX 通道，而音乐必须同时独占 RX 和 TX。

音乐启动现改为实际释放语音输出，并检查释放结果。暂时占用或释放失败时，每 250 ms 重试一次，仍受原有 8 秒交接期限限制；成功前不启动音乐。交接期间的取消和高优先级接管照常生效，释放后再次检查取消及连接代次。

正常语音待机继续保留预初始化行为，云端和网关字段不变。正常启动日志应出现 `speaker physical output released`、`music audio handoff ready`，随后是音乐采样率和 `state=playing`。

新增主机集成测试串联生产状态机、语音输出释放、音频引用计数和 RX/TX 申请函数；已覆盖旧路径复现、100 次交接、占用冲突、释放失败、超时和取消。该测试模拟物理硬件，不能替代实板播放验收。

## 7.0.183 弱网与换歌恢复

命令、ACK、状态字段和网关发送/中止接口保持不变。

- 换歌的 8 秒交接期限覆盖旧下载线程清理阶段。超时后结束新请求；音频时钟已经恢复时回到待唤醒，时钟仍未恢复时继续保持麦克风保护。
- 播放任务启动后，首段音频有 10 秒期限。持续少量返回数据、MP3 首帧迟迟无法解码时，结束本次请求并报告 `failed` / `first_audio_timeout`。此期限不限制整首音乐的长度。硬件时钟恢复依然必须完成后才能交还麦克风。
- 下载线程收到取消后，在 HTTP 连接、完整头字段或音频数据回调中关闭套接字的收发，打断持续少量来数的读取。HTTP 句柄和缓存仍由原线程清理，不跨线程释放。DNS/TLS 等操作的退出时间仍取决于底层超时。
- 云端音乐状态改由独立任务发送，音频线程不等待 WebSocket。发送失败按 0.5 / 1 / 2 秒间隔重试，单次状态最多保留 15 秒；断线或连接代次变化后丢弃旧状态。每个请求保留最新状态，尚未送出的 `playing` 可被终态替代。最多保存 8 个请求，满时拒绝新音乐，不挤掉已有状态。它是有界重试，不增加云端确认协议，也不承诺断网期间状态必达。
- 测试网关请求失败后，轮询间隔逐步增加到 5 秒；恢复成功后回到 500 ms，保留原有发送与中止操作。
- 表情切换期间延后菜单后台缓存预热，减少两项绘制工作叠加。实际菜单打开流程及视觉内容不变。

新增回归覆盖真实 Helix 慢速分片、首段输出期限、PA 准备跨越期限、旧线程未退出时换歌超时、状态发送竞态，以及 ESP-IDF 实际 HTTP 读取函数的取消行为。主机测试不等同于设备音质、帧率或长期稳定性验收。
