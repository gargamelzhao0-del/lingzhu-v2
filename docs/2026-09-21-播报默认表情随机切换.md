# 播报默认表情随机切换

普通对话开始实际播放 PCM，且本轮没有云端语义表情时，从原有“开心”和“调皮”资源中随机选择表情。每次独立随机保持 3000～7000ms（包含边界），到期重新选择表情和时长，允许连续选中同一表情；重复选中时原动画继续运行，不重新起播。

## 优先级与生命周期

- 云端表情仍由原有语义表情策略处理，接管后本轮不再执行本地随机切换，即使其后语义覆盖被清除。
- 未开始播放 PCM、恢复聆听、断开连接，以及 OTA、配网、会议、监控、低功耗、触摸覆盖期间不运行随机计时。
- 下拉菜单冻结期间暂停已有计时，关闭后继续剩余时间；冻结期间新开始的播报，在关闭菜单后才开始随机计时。
- 状态重复上报不会重置截止时间；UI 延迟时只进行一次到期选择，不追赶历史切换。
- 三根播报短柱与聆听波纹保持原有状态规则和动画；不修改原表情资源文件及云端协议。

## 实现

`main/nuwax_ui_v28/nuwax_face.c` 在已有 UI tick 中检查截止时间，用 `esp_random()` 选择表情和时长，通过既有播放器切换资源。状态仅保存在 UI 层，不伪造或发布云端语义表情。没有新增任务、定时器对象、动态内存分配或图像缓冲。

每次选择输出：

```text
nuwax_face: speaking fallback emotion=happy hold_ms=4382
nuwax_face: speaking fallback emotion=playful hold_ms=6127
```

上述数值为格式示例。连续随机选中同一表情时也会输出新的保持时长。

## 验证与交付

`tools/run-conversation-visual-checks.ps1` 使用真实 LVGL 和生产 `nuwax_face.c`，用可控随机数和时间验证计时上下边界、重复状态、重复选中、延迟 tick、云端覆盖、本轮禁止恢复随机、下一轮重新启用、菜单暂停、PCM 停止和特殊模式互斥，并回归小标绘制及冻结画面。

固件使用正式云端配置构建；未烧录实机。实机需验证超过 15 秒的普通播报、播报中云端下发表情、打断后恢复聆听，以及下拉菜单期间的稳定性。原有表情过渡的实机帧率仍需通过日志确认，不能由主机测试推定。
