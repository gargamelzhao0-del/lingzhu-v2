# 下拉菜单花屏修复

## 本轮实现

删除菜单中的整屏直出分支，统一使用 LVGL 底图绘制、组件缓存叠加和冻结表情遮罩路径。保留已有组件缓存和局部脏区优化。

这次没有保留一条默认关闭的有缺陷快路：删除了直出表面分配、像素循环、提前返回、菜单对全局输出 gate 的开关，以及该表面的销毁逻辑。因此菜单中断、反向、分配失败和销毁不会再遗留由菜单设置的全局输出抑制。

对应修复：

- 每次被刷新的区域先由 LVGL 生成有效底图，组件合成不再读入未初始化或上一帧残留的整屏缓冲。
- 圆外背景恢复统一经过原有过滤器，包含空圆整行复制和 Q4 边缘覆盖率处理，移除了直出两列漏写。
- 动画不再提前返回，位置、透明度、隐藏状态与背景进度使用原有同一套状态更新。保留已有隔帧内容更新策略；完成时仍强制应用终点状态。
- 移除忽略 present 返回值的菜单调用，屏幕发送继续由 LVGL 刷新任务及现有错误处理管理。
- 不再额外申请 259,200 字节（253.125 KiB）的直出表面。

本轮未更改 SD 录音/补传、显示任务优先级、SPI 时钟、内存保护和刷新完成令牌机制。当前构建配置的 SPI 时钟为 40 MHz，保留 2 秒 UI 性能日志。

## 验证

`tools/test-drawer-composition.py` 编译实际生产遮罩和刷新过滤器，使用确定的 LVGL 底图输入和冻结背景，与独立逐通道 RGB565 覆盖率参考比较：

- 0～1000 的全部 1001 个进度。
- 反向关闭、空圆行、亚像素左右边缘。
- 屏幕四周的裁剪及带行间距的局部矩形。
- 每行 padding、前后边界保护值不变。
- 关闭终点与冻结帧逐像素一致。
- 冻结帧不可用时保留 LVGL 有效输入。
- 菜单不再调用直出接口或控制全局 output gate。

上述测试通过。它检验生产像素处理代码，未替代实际 LVGL 栅格化、触摸输入或 QSPI 硬件测试。原缺陷的提取代码和复现结果保存在 `tmp/display-reveal-audit-20260918/`。

固件完整构建、RNNT 修复调用点和最终 ELF WebSocket 掩码校验通过。产品脚本前半部分的资源包（1423 帧）、表情格式/片段/组件过渡、菜单时序、UI bridge 等主机检查通过。

综合产品脚本没有全部通过：在 `tools/run-v2-product-host-checks.ps1:498` 的 BLE 配网静态契约处停止，已定位其中一项不匹配为 `wifi_manager.c` 的 `nuwax_wifi_set_provisioning_active` 函数内预期出现 `reconnect_armed → s_wifi_connect_requested → esp_wifi_connect()`。该文件及断言均不在本轮改动范围。没有删除或放宽此断言，未执行到的后续检查不计为通过；详见快照中的产品测试日志。
