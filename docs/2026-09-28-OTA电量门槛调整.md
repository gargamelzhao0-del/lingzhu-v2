# OTA 电量门槛调整

按本次需求，将“电量百分之 5 以上”落实为 5% 及以上（包含 5%），低于 5% 拒绝。

## 行为变化

| 场景 | 原行为 | 修改后 |
| --- | --- | --- |
| 5–29%，采样有效、电压正常 | 30% 门槛拒绝 | 允许 |
| 73%，CEDV 参数暂未认证，采样有效、电压正常 | power_unknown | 允许 |
| 5–10%，普通低电量提示已触发 | low_power | 允许 |
| 0–4% | 拒绝 | 拒绝 |
| 采样缺失、过期、无效或电池缺失 | 拒绝 | 拒绝 |
| 真实低电压（当前默认不高于 3400 mV） | 拒绝 | 拒绝 |

`battery_preflight_code()` 在收到指令和执行下载前使用同一准入函数；不再依赖 `soc_trusted` 或普通 `low` 提示，改为有效电量与 `hard_low_voltage` 检查。电池参数重校验仍照常执行，UI 电量提示及关机保护不变。

`CONFIG_NUWAX_OTA_MIN_BATTERY_PERCENT=5` 为包含下限的配置，已同步 Kconfig 默认值、产品配置覆盖及本地当前普通/正式构建配置。旧构建目录如使用独立 sdkconfig，须检查是否仍保留 30。

启动日志增加实际策略标识：

```text
OTA power admission revision=percent-v1 min_percent=5 profile_required=0 hard_voltage_guard=1
```

## 验证

- 策略主机测试覆盖 0%、4%、5%、10%、100%、越界值和无效/过期/缺失采样及真实低电压。
- 板级测试调用提取自设备源码的 `battery_preflight_code()`，遍历 0–100% 并验证 5% 的普通低电量提示不阻止升级，未认证参数也不阻止升级。
- 正式构建校验检查 BIN/ELF 身份、策略日志标识和最终 sdkconfig 的 5% 阈值。
- 新镜像启动确认仍检查实际供电、摘要及云端确认，不因电量低于下载门槛而额外判坏。

## 生效边界

此策略需运行新固件后生效。当前仍运行 7.0.99 的设备，在首次升级到新固件时仍按旧策略检查，需等其电池校验恢复且满足旧门槛后重新下发 OTA，或使用串口烧录。

本次沿用开发中的版本 7.0.100；若设备已运行另一份 7.0.100，同版本 OTA 仍会拒绝，需串口烧录或后续发布更高版本。旧 `artifacts/release-7.0.100` 包不包含本次修改，不能混用其 SHA。

降低门槛会减少可用电量余量，未认证的百分比也可能有误差。保留实际低电压保护及原有回滚机制；低电量下真实升级的稳定性仍需真机验证。
