## 0. 借鉴原则(3 条)

1. **只抄架构与接口设计,不抄实现**——xiaozhi 是 C++ 模板,我们是 C,实现不通用
2. **只抄能直接用或 1:1 替换的模块**——不抄声纹(产品决定在云端)
3. **借鉴前先看代码 0.5 天,再决定抄什么**——不要"全部抄"的盲目借鉴

## 1. 借鉴模块清单(7 个)

### 🟢 借鉴 1:`audio_service.cc` 架构
- **位置**:xiaozhi `main/audio/audio_service.cc`
- **价值**:**极高**——解决"全双工 + 唤醒态/休眠态 + VAD + 编码"全流程
- **抄什么**:4 态状态机接口 `Start / Stop / SendAudio / FetchAudio`
- **不抄什么**:具体实现(C++ 模板)、Lua 资源加载

### 🟢 借鉴 2:`afe_audio_processor.cc` 接口
- **位置**:xiaozhi `main/audio/processors/afe_audio_processor.cc`
- **价值**:**高**——抽象 `AudioProcessor::Process(samples) -> 改写 + 输出 debug`
- **抄什么**:Process 接口 + dual output 模式
- **不抄什么**:AFE 内部实现(ESP-SR 库,直接用)

### 🟢 借鉴 3:`wake_words/` 多 backend 抽象
- **位置**:xiaozhi `main/audio/wake_words/{afe,custom,esp}_wake_word.cc`
- **价值**:**高**——3 个 backend 抽象成 1 个接口
- **抄什么**:多 backend 注册表 + Kconfig 切换
- **不抄什么**:custom wake word 的 ESP-IDF 新 API(可能兼容性差)

### 🟡 借鉴 4:`mcp_server.cc` tool 列表
- **位置**:xiaozhi `main/mcp_server.cc`
- **价值**:**中**——11 个 MCP method 列表(音量/灯光/表情/...)
- **抄什么**:method 列表 + `AddTool` 注册风格
- **不抄什么**:Lua scripting(我们用 LVGL)

### 🟡 借鉴 5:`device_state_machine.cc` 4 态状态机
- **位置**:xiaozhi `main/device_state_machine.cc`
- **价值**:**中**——4 态:Unknown/Idle/Connecting/Listening/Speaking
- **抄什么**:4 态概念 + transition 规则
- **不抄什么**:具体 C++ 实现;我们扩为 5 态(加 Sleeping/Muting)

### 🟡 借鉴 6:`protocols/websocket.cc` 重连逻辑
- **位置**:xiaozhi `main/protocols/`
- **价值**:**中**——指数退避 + 心跳 + 状态机联动
- **抄什么**:重连 backoff 表(1s/2s/4s/8s/30s)
- **不抄什么**:MQTT 协议、UDP 音频

### 🟢 借鉴 7:`boards/` 抽象模式
- **位置**:xiaozhi `main/boards/`(30+ 板型)
- **价值**:**中-高**——`Board` 基类 + `GetAudioCodec()` 模式
- **抄什么**:Board 抽象模式
- **不抄什么**:具体 30+ 板 config(我们 Vocat 板专属)
