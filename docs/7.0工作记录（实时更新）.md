1. 先修正/验证 P3 health 工具本身的 I2S 时序，避免单任务 write/read 造成大量 timeout；建议复用 P2 smoke 的独立 TX task + RX capture 结构，并增加 4-slot 同步 Goertzel/RMS 输出。
2. 做 slot sweep 复核实际 reference 是否在 slot2，或是否迁移到其他 slot/软件侧路径；以当前真机串口为最高优先级证据，不再单信原理图或历史注释。
