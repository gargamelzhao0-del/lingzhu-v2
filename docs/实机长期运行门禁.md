# 实机长期运行门禁

`check-device-longrun-gate.ps1` 用于在继续功能测试前快速判断日志是否达到最低安全线：无崩溃、无音频丢帧、`internal_min >= 16384`、`dma_largest >= 8192`，并且唤醒输入无 partial read/timeout/input gap。

示例：

```powershell
.\tools\check-device-longrun-gate.ps1 -LogPath .\runtime-logs\device.log
```

该脚本是保守门禁，不替代 8 小时 soak、功耗测试和声学验收。若失败，应先收敛内存/生命周期，再继续扩大功能测试。
