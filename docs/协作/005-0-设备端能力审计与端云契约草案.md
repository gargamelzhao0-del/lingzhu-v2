## 2. 云端精判契约草案(设备端 → 云端)

### 2.1 上行(每帧或每会话)
```text
playback_id               string   当前播放窗口 ID(未播 = "")
audio_session_id          string   唤醒/对话 session
device_ts_ms              int64    设备本地时间戳(单调)
frame_seq                 int32    帧序号(per session 单调)
mic_chunk                 bytes    16k 16bit PCM(建议 20ms/帧)
ref_chunk                 bytes    同步 ref(可选,云端双麦精判时用)
volume                    float    当前播放音量 0..1
playback_state            string   "idle" | "playing" | "fading_out" | "ducked"
fade_progress             float    0..1,fade 进度
```

### 2.2 上行(诊断/质量)
```text
uplink_queue_ms           int32    上行队列累计延迟
uplink_drop_count         int32    本会话丢帧数
playback_drop_count       int32    本播放窗口丢帧数
tx_power_dbm              int      Wi-Fi 信号(可选)
battery_pct               int      电量(可选)
```

### 2.3 下行(云端 → 设备)
```text
duck                      { target_volume: float, fade_ms: int }
cancel                    { reason: string }
followup_listen           { duration_ms: int, pre_roll_ms: int }
```

## 3. 设备端职责边界

设备端**只做 4 件事**:
1. 稳定 mic 采集 + 上传(包含云端精判所需全部元数据)
2. 稳定播放(包含播放引用 + 帧序号绑定)
3. 接收并执行云端指令(duck/cancel/followup_listen)
4. 上报质量字段 + 异常状态

设备端**不做**:
- 不做最终人声判断(交给云端)
- 不做声纹识别(交给云端)
- 不做用户意图判断(交给云端)
- 不做回声消除精判(轻量抑制即可,精判给云端)
