## 0.5 Phase 0:生产安全 P0 修复(前置,1 周必须做)

**这是工程师深度审视发现的 10 个生产风险**——**重构之前必须先修**,否则重构中会**触发生产事故**。

### P0(立即修,1 周)

| # | 问题 | 位置 | 修复 |
|---|---|---|---|
| 1 | **`xTaskCreateStatic` 2 处无 caller**(死代码) | `nuwax_ai_partner_main.c:1342 / 1367` | 加 `__attribute__((unused))` 或删除,加 `-Werror=unused-function` |
| 2 | **`mic_input.c:302` reinit 不 deinit 老 buffer** | `mic_input.c:302` | reinit 路径前加 `if (raw_samples) free(raw_samples);` |
| 3 | **`audio_cleaner.c` reinit 路径 double-free** | `audio_cleaner.c` reinit 函数 | 加 `if (softref_buffer) { free; softref_buffer = NULL; }` |
| 4 | **35 处 `ESP_ERROR_CHECK` 触发即 hard reset**(分布 10 文件) | 全工程 `*.c` | 全部改为 `ESP_RETURN_ON_ERROR` + log + state 标记 |
| 5 | **`begin_wifi_connect_operation(...portMAX_DELAY)` 优先级反转** | `nuwax_ai_partner_main.c:1695` | mutex 改 `pdMS_TO_TICKS(1000)` timeout |

### P1(本月修)

| # | 问题 | 位置 | 修复 |
|---|---|---|---|
| 6 | **NVS 接口散落 5+ 文件** | speaker_playback / p3_afe_l3 / wifi_manager / others | **Phase 1.5:NVS 抽象层** |
| 7 | **19 处 ESP_LOGE 后没 return** | `nuwax_ai_partner_main.c` | 加 `return ESP_FAIL;` 或 `goto cleanup;` |

### 1.2 模块依赖矩阵(无环化)

|                | L1 | L2 | L3 | L4 | L5 | L6 |
|----------------|----|----|----|----|----|----|
| **L1 ESP-IDF** | -  | ✅ | ✅ | ✅ | ✅ | ✅ |
| **L2 HAL**     | ❌ | -  | ✅ | ✅ | ✅ | ✅ |
| **L3 抽象**    | ❌ | ❌ | -  | ✅ | ✅ | ✅ |

| **L6 应用**    | ❌ | ❌ | ❌ | ❌ | ❌ | -  |

**规则**:下层不能依赖上层。**任何反向依赖一律禁止**(makefile 钩子 + review 流程执行)。

### 1.3 三大规范(强制)

#### 规范 #1:命名
- ✅ `nuwax_<module>_<verb>()`(全小写 snake_case)
- ✅ `nuwax_<module>_t`(类型)
- ✅ `NUWAX_<MODULE>_<UPPER>`(宏)
- ✅ Tag `nuwax_<module>`(log)
- ❌ 禁止前缀 `static_` —— 用 `static`
- ❌ 禁止匈牙利

#### 规范 #2:错误返回
- ✅ 所有公共函数:返回 `esp_err_t`,`ESP_OK` 表成功
- ✅ 内部辅助:返回错误码可省 `nuwax_<module>_err_t`
- ❌ 禁止 `NULL + ESP_OK` 混表示

#### 规范 #3:日志
- ✅ 4 级:`ESP_LOGI / ESP_LOGW / ESP_LOGE / ESP_LOGD`
- ✅ 单行:`nuwax_<module>: <event>: <context>`
- ❌ 禁止 `printf`
- ❌ 禁止大块日志

## Phase 3:并发 + 错误 + 内存安全(Week 4)

### 3.1 所有 mutex acquire 加 timeout

**当前**(风险):
```c
xSemaphoreTake(s_lock, portMAX_DELAY);  // ❌ 永久等
```

**改进后**(强制):
```c
if (xSemaphoreTake(s_lock, pdMS_TO_TICKS(100)) != pdTRUE) {
    ESP_LOGE(TAG, "lock timeout, caller=%p", __builtin_return_address(0));
    return ESP_ERR_TIMEOUT;
}
```

**工具**:`scripts/check_portMAX_DELAY.sh` 全工程扫描,CI fail if found

### 3.2 全部错误码统一

**新增**:`protocol/protocol_errors.h`
```c
typedef enum {
    NUWAX_OK = 0,
    NUWAX_ERR_INVALID_ARG = 1,
    NUWAX_ERR_TIMEOUT = 2,
    NUWAX_ERR_WS_HANDSHAKE_FAILED = 100,
    NUWAX_ERR_AUTH_401 = 101,
    NUWAX_ERR_NO_AUDIO_FRAME = 200,
    ...
} nuwax_err_t;
```

**ESP_ERR 与 NUWAX_ERR 映射**:
| NUWAX | ESP_ERR |
|---|---|
| NUWAX_OK | ESP_OK |
| NUWAX_ERR_INVALID_ARG | ESP_ERR_INVALID_ARG |
| ... | ... |

**禁止在 module 内部定义 enum**(全部走 `protocol_errors.h`)

### 3.3 内存安全(全工程扫描 + 修)

**v1.1 修订**:**当前已满足** — 工程师严格 grep 显示**全工程 0 处 strcpy / sprintf / strcat**。**不需要新规则**。

**保留规则**(验证性):
- **不引入** `strcpy / sprintf / strcat / vsprintf`(已满足)
- **保留** `strlcpy / snprintf / vsnprintf / strncmp`(已满足)
- **如有新代码引入 unsafe 字符串函数**,CI 失败

**工具**:`scripts/check_unsafe_string.sh` 全工程 grep,CI fail

**主工程预计修改**:**~50 处**

### 3.4 任务优先级倒置修复

**当前**(风险):
```c
// low-priority task 持有 mutex 阻塞 high-priority task
xSemaphoreTake(s_lock, portMAX_DELAY);  // 低优先级持有
// high-priority task 想获取 mutex → 永久阻塞
```

**改进**:`xSemaphoreTakeRecursive + priority inheritance mutex`
```c
// ESP-IDF v5+ mutex 自动开启 priority inheritance
```

```bash
#!/bin/bash
# 禁函数
for func in "strcpy(" "strcat(" "sprintf(" "vsprintf("; do
    m=$(grep -rn "$func" main/ 2>/dev/null | grep -v "/legacy/" | grep -v "// SAFE:")
    if [[ -n "$m" ]]; then

        echo "$m"
        exit 1
    fi

```

### 工具 #3:`scripts/check_doc_coverage.sh`
```bash
#!/bin/bash
total=$(find main/ -name "*.h" -not -path "*/legacy/*" | wc -l)
with_doc=$(grep -lE "^/\*\*\s*\n?.*@file" main/*.h main/**/*.h 2>/dev/null | wc -l)
rate=$((with_doc * 100 / total))
if [[ $rate -lt 90 ]]; then
    echo "❌ doc coverage $rate% < 90%"
    exit 1
fi
echo "✅ doc coverage $rate% (target > 90%)"
```
