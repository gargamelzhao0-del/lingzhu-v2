## 1. 总目标

设备端实现**全双工流式音频 + 第一轮过滤 + 唤醒态/休眠态切换 + 状态消息驱动 UI**。
所有精确人声判断、声纹识别、用户意图判断、最终打断裁决**全部由云端**完成,设备端不参与。

### 3.2 帧格式

#### 上行 NA 二进制帧(设备端 → 云端)

```
[2B 帧头:NA标识符(0x4E41)][2B 帧序号seq][4B 时间戳ms][N B PCM16/Opus]
```

#### 下行 NA 二进制帧(云端 → 设备端)

```
[2B NA标识符(0x4E41)][2B 帧序号seq][4B 时间戳ms][N B PCM16/Opus]
```

帧标识符:固定 0x4E41(ASCII "NA")。

## 4. 5 维状态驱动

### 4.1 状态消息(云端 → 设备端)

| 状态类型 | 字段 | 设备端动作 |
|---|---|---|
| `playback_state.playing` | bool | 启动 `speaker_playback_resume` / `speaker_playback_pause` |
| `playback_state.fade_out_ms` | int | 平滑淡出 |
| `playback_state.volume` | 0-100 | `speaker_playback_set_volume` |
| `avatar_state.expression` | enum | LVGL 表情切换 |
| `avatar_state.eye_action` | enum | 眨眼/闭眼 |
| `led_state.color` | RGB | `touch_gesture_set_led` |
| `display_state.page` | enum | LVGL 页面切换 |
| `session_state.active` | bool | 进/出聆听态 |
| `session_state.timeout_ms` | int | 静音超时切休眠 |
| `error_state.code` | int | 弹错误提示 |

### 4.2 设备端状态变更协议(`device_command`)

云端下发的 4 个 005 扩展命令:
- `duck_playback`:120ms 淡入到 30% 音量
- `fade_playback`:500ms 平滑淡出
- `followup_listen`:8s 持续收音 + 600ms pre-roll
- `cancel_playback`:强制取消(不等 fade)

## 9. 风险评估

| 风险 | 影响 | 缓解 |
|---|---|---|
| 设备端 AEC 残余 > 5% | 上行污染,云端二轮 AEC 压力大 | 005-2 加 4 类门禁 |
| 状态消息时延 > 200ms | UI 卡顿 | 005-4 走 RTOS 高优先级任务 |
| 唤醒词误触发 | 频繁进入聆听态,费电 | 005-1 加单 mic 能量门禁 |
| 唤醒态切换爆音 | 用户体验差 | 005-1 加切换缓冲 + 软淡入 |
| 全双工时延 > 200ms | 云端 pre-roll 不够 | 005-1 优化 mic→upload 链路 |
| 端云 URL 切换风险 | 服务端地址变更需 OTA | 005-5 加 NVS 保存 + 远程配置 |

## 10. 验收标准

阶段 5 完成后,必须达到:

1. **全双工流式**:播放中设备端能持续上行音频,服务端二轮 AEC 后基本无回声
2. **唤醒态/休眠态正确切换**:唤醒词 < 500ms 内识别 → 立即进聆听态;智能体"对话结束"或 30s 静音后切休眠
3. **状态消息驱动 UI**:云端下发 `playback_state` / `avatar_state` / `led_state` / `display_state` < 100ms 内生效
4. **杂音过滤有效**:键盘声、风扇声、媒体声被设备端第一轮过滤(< 5% 上行包含明显杂音)
5. **生产链路 0 精判**:设备端生产固件中 P3/P5/P6 精判代码**未链接进主流程**
