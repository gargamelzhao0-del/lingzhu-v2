## 模拟器检查

独立解压模式先设置 ESP-IDF `v6.0` 路径：

```powershell
$env:IDF_PATH = "C:\esp\v6.0\esp-idf"
```

在 `simulator` 目录执行：

```powershell
node --check app.js
node --test qr-codec.test.cjs
python -m py_compile bridge.py
python -m unittest bridge_logic_test.py
```

预期：QR 16 项、Bridge 27 项、最小测试网关 4 项通过。

在 `test-gateway` 目录执行：

```powershell
npm test
```

## 协议检查

项目根目录执行：

```powershell
node NuwaxAIPartner/tools/protocol/validate-protocol-assets.js
```

`fake-device-conformance.js` 是针对已启动的语音 WebSocket 网关的另一项
一致性测试，必须显式传入 `--url` 和测试鉴权参数，不是本 BLE 交付包的
独立复核命令。

## 固件检查

使用 ESP-IDF v6.0：

```powershell
idf.py reconfigure
idf.py build
```

本包不包含真实 `deviceSecret`、Wi-Fi 密码、PoP 量产值、私钥或运行日志。
模拟器 USB 按钮还要求固件使用联调配置
`CONFIG_NUWAX_PROVISION_USB_CONTROL_ENABLE=y`；生产发布必须设为 `n`。
