# 最终代码审计结论

审计日期：2026-07-26。

## 可交付结论

本包可提交 APP 工程师进行 Android Provider 首轮真机联调。当前唯一协议为
Security 2 + `device-info` + `vox-config` + 官方 `prov-scan/prov-config`，
不存在第二套签名 bundle 流程，也不支持 SoftAP fallback。

设备端已实现并合入主工程：

- 按 endpoint 名称创建和注册 `device-info`、`vox-config`。
- 校验 `deviceId` 等于硬件 UID，防止配置发给错误设备。
- 将动态 `gatewayUrl`、`deviceSecret` 原子保存到 NVS，重启后恢复。
- 使用动态密钥发送 `X-Bridge-Token` 和 `hello.device_secret`。
- 以 `GOT_IP` 作为 `WIFI_READY`，云端状态独立呈现。
- 本地菜单或鉴权 WebSocket 命令可重新进入可回滚 BLE 配网。
- 联调固件提供物理 USB Serial/JTAG 控制模块；模拟器只在确认精确 BLE
  广播后报告设备已进入配网模式。

## 最终修正

- 删除交接包内旧 `cloud-config`/签名 onboarding 网关，换成零依赖最小测试网关。
- 收紧 URL：ASCII `ws/wss`、禁止账号密码/fragment/IPv6 literal、校验端口。
- 收紧密钥：只接受 1..95 个可打印 ASCII 字符，匹配 HTTP 鉴权头语义。
- 模拟器和固件使用相同校验规则；增加对应边界测试。
- 明确 `deviceSecret` 来自现有 `bind`，`gatewayUrl` 来自 APP 环境或后端配置；
  当前已观察的 `bind` 响应不包含 `gatewayUrl`。
- USB 串口自动选择只接受唯一 Espressif VID `0x303A` 设备；多设备时必须
  显式设置 `NUWAX_DEVICE_SERIAL_PORT`，不会向唯一的非 ESP 串口误发命令。
- 启动脚本支持自定义模拟器端口并在端口占用时给出明确错误。
- `/api/reprovision` 要求 `deviceId + serviceName`，并以
  `ble_advertisement_confirmed` 收敛；`command_forwarded` 只是网关备用路径
  的内部进度，不再作为页面成功结果。

## 验证结果

- ESP-IDF `v6.0` / commit `662a3be354759d9487bf4b1a629fadb766cb1800` 构建通过。
- `espressif/network_provisioning` `1.2.4` / commit
  `2de4980640bbe3d2d69473d7251640039e185b92` 与本地组件元数据一致。
- QR `16/16`、Bridge `27/27`、最小测试网关 `4/4`。
- 独立复制包启动成功：模拟器 HTTP 200，自带测试网关健康。
- 最终镜像已烧录，正式联调 WSS 动态绑定保留并持续收到应用层 `pong`。
- 模拟器按钮从正式 WSS 在线状态经 COM8 触发成功，固件 ACK、回滚记录、
  重启、精确 BLE 广播、再次配网和正式 WSS 恢复均通过。

## 不能扩大表述的边界

该结论是“首轮 APP 联调可交付”，不是“量产发布可交付”。逐设备 PoP、
NVS Encryption、Flash Encryption、Secure Boot、20 次以上重复配网、长时间
在线和正式后端所有权校验的远程配网 API 尚未完成验收。历史上出现过一次
未复现的 `StoreProhibited` 自动恢复事件，必须继续做长稳回归。
