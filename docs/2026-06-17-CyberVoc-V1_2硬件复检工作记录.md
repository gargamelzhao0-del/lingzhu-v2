# 2026-06-17 CyberVoc V1.2 硬件复检工作记录

## 1. 复检结论

本次以用户确认能跑通的 `cyberkit-main/main/boards/CyberVoc-Board-V1_2/` 为真实 PCB 参考源,重新核对 7.0 工程硬件相关代码和文档。结论:

- 7.0 主线硬件应固定为 **CyberVoc V1.2**,不是旧 ESP-VoCat/EchoEar V1.0 表。
- 旧 `DIN=GPIO15 / PA=GPIO4 / LCD_RST=GPIO3 / LCD_DC=GPIO45 / LCD_TE=GPIO8 / TOUCH=GPIO7` 判断已作废。
- 7.0 代码中的关键硬件定义、vocat 构建脚本和权威文档已按 V1.2 修正。
- 已完成 `-Board vocat -EnableP2AudioSmoke` 构建验证,生成固件 `NuwaxAIPartner/build-vocat-v12-hwcheck/NuwaxAIPartner.bin`。

## 2. V1.2 权威硬件口径

| 模块 | 结论 |
|---|---|
| I2C | SCL=GPIO1,SDA=GPIO2;ES8311=0x18,ES7210=0x40,BQ27220=0x55,BMI270=0x68 |
| 音频 | MCLK42/BCK40/WS39/DOUT41/**DIN3**/**PA15**;GPIO48 需启动早期拉高 |
| POWER_CTRL | GPIO9;参考固件运行态输出 LOW,7.0 vocat 默认对齐为 HOLD_LOW |
| LCD | QSPI SCK18/CS14/D0-D3=46/13/11/12;RST47 且 active-high;BL44 且 active-high;无 DC/TE |
| Touch | CST816S/CST816-family;INT10,RST NC,TOUCH_PAD2=6;I2C 未 ACK 仍待硬件侧排查 |
| SD/UART | SD CLK/CMD/D0=16/38/17;UART1 TX/RX=5/4 |

## 3. 本次代码修正

- `main/Kconfig.projbuild`
  - vocat 板名改为 CyberVoc V1.2。
  - `NUWAX_DISPLAY_PIN_DC` 对 vocat 默认 -1。
  - 新增 `NUWAX_DISPLAY_RST_ACTIVE_HIGH`,vocat 默认 y。
  - `NUWAX_DISPLAY_BL_ACTIVE_LOW` 对 vocat 默认 n。
  - POWER_CTRL vocat 默认 HOLD_LOW。

- `main/display.c`
  - ST77916 reset 改为按配置选择 active-high/active-low,避免 V1.2 RST47 被低有效时序误留在复位态。
  - backlight/reset 日志输出改为稳定 0/1 宏,避免 active-high 场景下 Kconfig bool 未定义导致编译风险。

- `main/board/nuwax_board.c`
  - QSPI banner 不再打印不存在的 DC。
  - 启动日志打印 reset/backlight 极性。

- `main/board/esp_vocat_v1_0_pins.h`
  - 重写文件头为 CyberVoc V1.2 权威 pin map。
  - 保留兼容文件名/符号,但宏值和注释按 V1.2 冻结。

- `main/board/nuwax_power_ctrl.h`
  - 更新为 V1.2 GPIO9 运行态拉低说明。

- `main/touch_input.c`
  - 用户可见日志从 CST816D 改为 CST816-family,避免把型号误判当成硬件结论。

- `build-opus-firmware.ps1`
  - `-Board vocat` 强制写入 V1.2 LCD/touch/POWER_CTRL 关键配置。
  - `Set-SdkconfigInt` 支持负数,避免 `RST=-1`/`DC=-1` 重复追加。

## 6. 剩余风险

- 触摸 CST816S/CST816-family 仍未在 I2C ACK,需要硬件侧继续查供电、FPC、RST/INT/地址/唤醒条件。
- GPIO45/GPIO8 在 V1.x 不应再当 LCD_DC/TE 使用,真实用途仍待硬件侧确认。
- 本次完成了构建验证,未重新烧录 COM8 做屏幕/触摸/音频真机回归。

## 7. 产品负责人判断

核心硬件误判已经修正到位:7.0 工程的 V1.2 pin map、构建入口、LCD reset/背光极性、GPIO9 默认策略、音频 DIN/PA/CODEC_PWR 口径已经和可跑通参考代码对齐。不能称为“完全闭环”的只剩真机回归项:触摸未 ACK、GPIO45/GPIO8 真实用途、以及本次新固件烧录后的屏幕/音频/电源行为复测。
