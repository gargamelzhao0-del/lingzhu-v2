# OTA 顶部进度胶囊

> 本文保留旧版设计记录。当前代码已采用 [OTA 开机 Logo 升级界面](2026-09-21-OTA开机Logo升级界面.md)，布局、遮挡与暂停行为以新文档为准。

将原 `update: N%` 标签替换为顶部黑底白边圆角胶囊，包含下载图标、“更新中”、真实百分比和白色圆头进度条。360×360 屏幕下位置为 `(68,48)`，尺寸为 `224×52`；进度条为 `182×6`，未完成部分为深灰色。

仅修改 OTA 显示层。`nuwax_face.c`、表情播放器、表情资源包、底部状态小标与播报随机表情逻辑均未修改。该组件不设置任何表情，也不修改升级协议、进度来源或音频控制。

## 生命周期与开销

- 隐藏状态不刷新；激活时直接显示当前进度，后续数值变化以 180ms 插值推进进度条，不添加闪烁或循环动画。
- 同一百分比的重复状态通知不重新设置标签或启动动画。
- 百分比限制在 0～100，结束/失败后隐藏；隐藏时取消尚未结束的条形动画，下一次更新重新开始。
- 4 个常驻 LVGL 对象（容器、标题、百分比、条形），下载图标使用圆头线段绘制。百分比使用静态小缓冲，新增字体仅含 14 个必要字形，位图 1530 字节。
- 不分配整屏像素缓存，不新增任务或独立周期定时器；进度插值复用 LVGL 动画机制。

## 验证

`tools/run-conversation-visual-checks.ps1` 编译实际 LVGL 与生产组件，验证组件范围外像素保持一致、0/62/100% 显示、越界百分比限制、重复通知无刷新、隐藏/删除取消动画及再次创建，并回归现有聆听/播报小标和随机表情策略。

`tools/preview-ota-progress.py` 从原有 `emotion-assets.bin` 解码休眠动画循环的首帧，用其作为原生渲染底图。预览不重新绘制或修改表情。预览是原生 UI 静态帧，不代表实机动画帧率。

正式配置完整构建后交付固定快照。尚未烧录实机；需在真实 OTA 过程中确认进度出现、推进、结束/失败隐藏，以及原有表情动画继续运行。

## 开机直接显示的专用测试固件

`tools/build-sd-replay-formal.ps1 -OtaPreview` 会显式打开 CMake 开关 `NUWAX_OTA_PROGRESS_BOOT_PREVIEW`，不带该参数时显式关闭，避免开发缓存将演示带入普通版本。

UI 创建时立即显示 62%，保持 3 秒，然后以 20 秒完成 0～100% 的模拟进度，100% 保持 2 秒后循环。仅多一个 500ms 的 LVGL 演示定时器；既有进度条插值仍为 180ms。

模拟进度只送入 OTA 提示组件内部，不发布 `ota_update_active`，不调用升级控制器、不下载或写入固件、不暂停音频或切换表情。正式云端 SD 路由不变。真实 OTA 一旦激活，会永久停止本次开机的演示定时器，让真实进度独占提示；真实升级结束后按正式逻辑隐藏。

主机检查命令 `tools/run-conversation-visual-checks.ps1 -OtaPreview` 验证开机可见、普通状态不隐藏、模拟计时推进和真实升级接管。普通检查不带参数，验证演示默认关闭。
